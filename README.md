# **Kotlin Basic Calculator** ➕➖✖️➗

Kotlin Basic Calculator is a simple Android application that performs basic arithmetic operations including addition, subtraction, multiplication, and division. It provides a user-friendly interface for quick and efficient calculations. 📱

## **Introduction** 🚀

Kotlin Basic Calculator is designed to offer a straightforward solution for performing basic arithmetic operations on Android devices. Built with Kotlin, it ensures a smooth and responsive user experience, making everyday calculations easy and accessible.

## **Installation** ⚙️

To install Kotlin Basic Calculator, follow these steps:

1. Clone the repository: **`git clone https://github.com/TunahanAkdere/Kotlin-BasicCalculator.git`** 🧑‍💻
2. Navigate to the project directory: **`cd Calculator`** 📁
3. Open the project in Android Studio. 💻
4. Sync the project with Gradle files. 🔄
5. Build and run the project on your Android device or emulator. 📲

## **Usage** 🛠️

To use Kotlin Basic Calculator, follow these steps:

1. Open the project in Android Studio. 💻
2. Build and run the application on your device or emulator. 📲
3. Use the calculator interface to perform basic arithmetic operations:
   - Enter numbers using the numeric keypad. 🔢
   - Choose an operation (addition, subtraction, multiplication, or division). ➕➖✖️➗
   - View the result displayed on the screen. 📈
